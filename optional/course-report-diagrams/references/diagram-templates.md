# 常见图模板

## 1. 业务流程图

### 适用场景

- 系统业务流程
- 数据流转流程
- 控制闭环流程

### 默认工具

- Mermaid

### 输出要求

- 优先使用 `flowchart TD`
- 流程步骤按真实业务顺序排列
- 节点文字控制在一行或两行内
- 如果是报告章节图，附带图注

### 常见图注

- `图 1-1 系统业务流程图`
- `图 4-2 远程控制业务流程图`

## 2. 系统整体架构图

### 适用场景

- 前端 / 后端 / 数据库 / 通信层
- 模块分层
- 技术路线说明

### 默认工具

- Mermaid

### 输出要求

- 用分层或分组表达结构
- 清楚标出协议、数据流、模块边界
- 不要写与项目无关的技术

### 常见图注

- `图 2-1 系统整体架构图`

## 3. 数据库 E-R 图

### 适用场景

- 数据表关系
- 主外键关联

### 默认工具

- Mermaid `erDiagram`

### 输出要求

- 实体名使用表名或业务实体名
- 关系要体现一对多、多对一
- 字段列举只保留关键字段
- 对报告而言，优先简化，不画成过密数据库全景图

### 常见图注

- `图 3-1 数据库 E-R 图`

## 4. 类图

### 适用场景

- 面向对象设计
- 实体类 / 服务类 / 控制类关系

### 默认工具

- PlantUML

### 输出要求

- 用标准类图关系
- 类名、属性、方法分层清楚
- 不要把所有实现细节都塞进去

### 常见图注

- `图 4-1 核心类关系图`

## 5. 用例图

### 适用场景

- 用户角色与系统功能关系

### 默认工具

- PlantUML

### 输出要求

- 角色放左侧
- 用例放系统边界内
- 不要把页面按钮级动作全部画进去

### 常见图注

- `图 1-2 系统用例图`

## 6. 时序图

### 适用场景

- 请求处理时序
- 控制指令闭环

### 默认工具

- Mermaid 或 PlantUML

### 输出要求

- 参与者命名稳定
- 先后顺序必须严格对应业务
- 只保留关键消息

### 常见图注

- `图 4-3 指令下发时序图`

## 推荐输出模板

### 模板 A：用户要报告插图

先给：

`推荐图注：图 x-x xxx`

再给：

对应 Mermaid / PlantUML 代码块

最后给：

- 一句使用说明，例如“直接粘贴到 Mermaid Live Editor 渲染即可”

### 模板 B：用户只要代码

- 直接给代码
- 最多补一行图注建议

### 模板 C：用户要按之前标准

- 不重新解释风格
- 直接按黑白专业风、中文命名、紧凑布局输出
