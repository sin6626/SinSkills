# 课设报告制图规范

## 默认风格

- 面向课设、实验报告、课程设计、毕业设计
- 视觉基调：简洁、专业、可打印、可插入 Word / WPS / PPT
- 默认配色：黑白或低饱和灰阶
- 默认语言：中文
- 默认目标：优先保证结构清楚，其次才是美观

## 命名规范

- 标题和图注要学术化，避免口语
- 节点命名尽量短
- 常用命名示例：
  - `前端页面`
  - `后端服务`
  - `数据库`
  - `设备端`
  - `实时数据`
  - `历史数据`
  - `错误信息`
  - `控制指令`

## 图注规范

- 默认图注格式：`图 x-x xxx`
- 示例：
  - `图 1-1 系统业务流程图`
  - `图 2-1 系统整体架构图`
  - `图 3-1 数据库 E-R 图`
  - `图 4-1 权限拦截处理流程图`

## 版式偏好

- 报告页内优先紧凑、规整、便于截图或导出 PNG
- 业务流程较长时可用纵向布局
- 分层架构、模块结构一般优先横向或上下分层
- 不要默认输出花哨背景
- 不要默认输出彩色强调块

## 当前用户偏好

- 用户经常要“能直接贴到报告里”的代码
- 用户偏好先拿到代码，再去网站渲染或导出 PNG
- 用户对“黑白专业风”“不要乱配色”“节点清楚”比较敏感
- 如果没有特别说明，优先按这个标准输出
